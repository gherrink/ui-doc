# Commit Message Examples

## Simple Feature

```
feat(core): add custom tag transformer support

Co-Authored-By: Claude <noreply@anthropic.com>
```

## Bug Fix

```
fix(html-renderer): resolve CSS class escaping issue

Co-Authored-By: Claude <noreply@anthropic.com>
```

## Multi-Package Fix

```
fix(html-renderer,rollup): correct asset path resolution

Co-Authored-By: Claude <noreply@anthropic.com>
```

## Documentation

```
docs(vite): update configuration examples

Co-Authored-By: Claude <noreply@anthropic.com>
```

## Breaking Change with !

```
refactor(node)!: change file finder API

Co-Authored-By: Claude <noreply@anthropic.com>
```

## Breaking Change with Footer

```
feat(core): redesign block parser interface

BREAKING CHANGE: BlockParser now requires async transform methods

Co-Authored-By: Claude <noreply@anthropic.com>
```

## Release Commit

```
chore(release): v0.3.1

Co-Authored-By: Claude <noreply@anthropic.com>
```

## With Body

```
feat(demos): add dark mode toggle

Implements theme switching using CSS custom properties.
Stores preference in localStorage.
```
