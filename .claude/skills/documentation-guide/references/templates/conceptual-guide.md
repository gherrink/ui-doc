## Template usage notes

**Start with "what":** Define the concept before explaining how it works.

**Build understanding:** Progress from simple to complex.

**Use examples:** Abstract concepts need concrete examples.

**Diagrams help:** Visual representations often clarify architecture concepts.

**No step-by-step:** Conceptual guides explain; tutorials teach procedures.

**Connect to practical use:** Always show why understanding this concept helps the reader.
