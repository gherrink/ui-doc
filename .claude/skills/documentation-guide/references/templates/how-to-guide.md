## Template usage notes

**Problem-first:** Start with the problem, not background information.

**Task-focused:** Stay focused on one specific task. Link to other guides for related tasks.

**Working code:** Provide complete, working code that can be copied.

**Assume knowledge:** Unlike tutorials, how-to guides can assume the reader has UI-Doc experience.

**Variations:** Include common variations but don't exhaustively cover every possibility.
