## Template usage notes

**Sequential steps:** Each step must build on the previous. Never assume knowledge from later steps.

**Complete code:** Show the full file contents at checkpoints, not just diffs.

**Verify each step:** Include checkpoints so readers know they're on track.

**15-30 minutes:** Keep the tutorial completable in one session.

**Single focus:** Teach one workflow, not multiple optional approaches.
